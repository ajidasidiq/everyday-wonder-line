A program that writes one sentence, 80 characters, that makes a small everyday moment strange and new — a photocopier that hums your name wrong until you answer to it — for make.fun's "Everyday Wonder, Two Days to Find the Line" bounty.

## Run it

```sh
python3 main.py
```

`main.py` writes the sentence to `/output/entry.txt`. Deterministic: the same sentence on every run, no input, no network, no randomness. A built-in gate self-check verifies the output is a single sentence of 1–200 characters before it is written.
